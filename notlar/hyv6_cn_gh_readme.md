## 📖 故事梗概

某日，我斥资数百大洋购入一块**海康威视 C500 1TB**，心想："国产牛逼，冲冲冲！"

然后它挂了。

不是表演型挂法。是那种——电脑完全不识别、BIOS 里看不见、硬盘盒插上去只亮灯不进系统的**真·死透了**。

Windows 磁盘管理？空白。DiskGenius？不存在的。  
此刻我才明白，我买的不是固态硬盘，是一块 **1TB 的电子镇纸**。

## 🧠 修复原理（说人话版）

SSD 固件崩溃 ≈ 硬盘得了失忆症，忘记自己是谁。

这时候需要**短接 ROM 触点**，让它进入出厂模式（像个婴儿一样只认量产工具），然后用正确的固件重新"教它做人"。

这个过程叫做 **MPTool 开卡**。

---

## ⚠️ 踩过的坑（给你省 30 小时）

### 坑 1：硬盘盒不对
- ✅ **必须用 JMS583 主控的硬盘盒**
- ❌ RTL9210 主控的盒子识别不了 ROM 模式
- 我换了 3 个硬盘盒才发现这个问题。别学我。

### 坑 2：短接姿势
- 短接 ROM 触点 → **保持短接** → 插入 USB → 等工具识别 → **松开**
- 松早了=白插，松晚了=工具不认
- 建议：用镊子，手别抖

### 坑 3：量产工具版本
- 穗穗工具站有几十个 MAP1202 的包
- 正确的包是这个：**`MAP1202_B47R-C_0_01_009d-SVN09954`**
- 别下成 B37R 的，那是另一个颗粒

### 坑 4：参数设置
- **Tool Type**：选 `MPT`（不是 Sort、不是 MPTP）
- **Preformat Mode**：选 `Inherit FW BB`（继承原厂坏块表，不然开出来容量不对）

## 🚀 开卡步骤

### 准备工作
1. 准备一个 **JMS583 主控的硬盘盒**
2. 下载本仓库的量产工具并解压
3. 拆开 SSD 外壳（已过保，拆就拆了）
4. 找到板上两个 ROM 触点（通常在主控旁边，标着 ROM / J1）

### 开卡流程
```
1. 短接 ROM 两个触点（镊子/导线）
2. 保持短接，插入 USB
3. 打开量产工具，点「Scan Drive」
4. 看到设备出现 → 松开短接
5. 确认参数：
   - Tool Type: MPT
   - Preformat Mode: Inherit FW BB
   - Capacity: 自动（不要手动改）
6. 点「Start」
7. 泡杯茶，等 3-5 分钟
8. PASS → 拔掉重插 → 进磁盘管理初始化 → 完工 🎉
```
